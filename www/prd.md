
# QuickMath 前端独立版 - 产品需求文档（PRD）

## 一、项目概述

本版本为 QuickMath 的“纯网页练习版”，部署于 `/www` 目录下，供用户通过浏览器直接访问并练习速算题目。该版本不依赖后端服务或数据库，所有数据使用浏览器的 localStorage 储存，仅保存用户自己的记录。适合在本地部署或分享链接给他人独立使用。

---

## 二、开发原则

- ✅ **逻辑和网页样式应尽可能复用原 Flask 应用**
  - 包括题型结构、答题方式、批改规则、历史查看等
  - 页面布局、CSS 样式、组件结构等可复制原有模板，适当删减后端依赖
- ✅ **不引入构建流程或框架工具链**
  - 所有页面使用纯 HTML/CSS/JS 编写
  - 不使用 Vue/React/TS 等前端框架
- ✅ **兼容移动端浏览与触屏操作**

---

## 三、功能模块

### 1. 配置页（index.html）

- 选择题目模块 + 每个模块的题目数量
- 使用表单复选框、下拉/输入数字框
- 点击“开始练习”后，将配置存入 localStorage 并跳转到 quiz.html

模块举例：
- 2位 × 1位 乘法
- 两位数加减（答两个）
- 三位数加减
- 多位 ÷ 两位（答商首位）
- 多位 ÷ 三位（答商前两位）

---

### 2. 答题页（quiz.html）

- 页面载入后根据 localStorage 配置生成题目
- 每题一个或多个输入框，编号 + 运算式 + 答题框
- 计时器自启动，显示用时
- 所有输入框绑定 `oninput` 自动保存答案到 localStorage
- 页面刷新后保留答题状态
- 底部按钮：“提交答卷”

---

### 3. 答案批改页（result.html）

- 根据用户答案与标准答案比对（客户端 JS 逻辑）
- 每题显示是否正确、正确答案（如有错误）
- 显示总成绩：答对数 / 总题数，正确率百分比
- 结果保存到 localStorage 历史列表中

---

### 4. 历史记录页（history.html）

- 展示所有练习记录（时间 + 得分 + 配置）
- 点击每一项可查看当次答题详情（题目、答案、对错）
- 页面可滚动浏览所有历史记录

---

## 四、数据存储结构（localStorage）

- `quickmath_config`：最近一次题目配置
- `quickmath_current`：当前答题中题目、答案、时间
- `quickmath_history`：数组，保存所有已提交记录

```js
// 示例结构
localStorage["quickmath_history"] = [
  {
    date: "2025-05-01 10:30",
    modules: [{ type: "2x1_mul", count: 20 }],
    questions: [...],
    userAnswers: { q1: "56", q2: ["123", "88"] },
    score: "18/20",
    percent: 90
  }
]
````

## 五、页面结构说明（保持与 Flask 模板一致）

| 页面    | 原路径        | 新路径                 | 说明         |
| ----- | ---------- | ------------------- | ---------- |
| 配置页   | `/config`  | `/www/index.html`   | 选择模块与数量    |
| 答题页   | `/quiz`    | `/www/quiz.html`    | 展示题目，答题与计时 |
| 结果页   | `/result`  | `/www/result.html`  | 批卷后展示结果    |
| 历史记录页 | `/history` | `/www/history.html` | 查看答题记录     |

> 你可以复制 Flask 模板中的 HTML，并剥离 Jinja 模板语法（如 `{{ }}`），改为 JS 动态渲染。
