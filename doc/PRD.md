# QuickMath - 产品需求文档（PRD）

## 一、项目概述

QuickMath 是一个基于 Flask 的速算练习服务，支持多种可配置题型模块，提供完整的答题、缓存、防丢失、自动批卷和历史记录功能。目标是提供一个适用于学生或速算爱好者的在线训练平台，专注练习效率和用户体验。

---

## 二、核心功能模块

### 1. 模块配置页

- 用户可选择不同题型模块和每个模块的题目数量。
- 题型模块包括：
  - 两位数 × 一位数乘法（答案为单个数）
  - 两位数加法与减法混合（两个框，分别答加法与减法）
  - 三位数加法与减法混合
  - 多位数 ÷ 两位数（仅答商的首位）
  - 多位数 ÷ 三位数（仅答商的前两位）
- 页面形式：多选 + 数字输入控件。

---

### 2. 出题系统（后端）

- 根据所选模块生成题目，打乱顺序。
- 每道题包含唯一 ID、题干（A 与 B）、题型 type 和正确答案。
- 所有题目及配置存入用户 session 或数据库缓存。

---

### 3. 答题页面

- 页面展示全部题目，支持上下滚动。
- 各题目对应输入框（可支持多输入框类型）。
- 页面计时器从点击“开始答题”后启动。
- 所有输入框绑定 onBlur/onChange 事件，自动将用户答案缓存到浏览器 localStorage。
- 页面刷新后自动恢复用户已填答案。

---

### 4. 批卷功能

- 点击“提交”按钮后，系统比对用户答案与标准答案。
- 批改逻辑依据题型不同灵活处理（如加减两项、多位除法需截取位数）。
- 返回正确/错误信息，并展示正确答案。
- 页面展示得分与正确率（格式：18/20，90%）。

---

### 5. 历史记录

- 每次练习结果都保存，包括：
  - 练习时间
  - 所选模块及题数
  - 所有题目与用户作答
  - 得分情况
- 可从历史记录中点击查看每一场练习的详细答题情况。

---

## 三、系统架构建议

### 前端
- HTML + JS（支持缓存输入）
- Bootstrap 或 Vue 以提升交互体验
- 使用 localStorage 保存用户输入与恢复

### 后端
- Flask（Python）
- SQLite 记录题目与答题历史
- 使用 Jinja2 模板渲染页面

---

## 四、非功能性需求

- 页面需支持移动端浏览
- 页面答题过程中应尽量减少刷新与丢失风险
- 答案与题目 ID 需一致，确保批卷准确性
